Estado: sem tag, release, push ou deploy. Canal planejado: `gabrielzucco/cerebro-inevita`.
Esta branch une o histórico de Cockpit/Hermes/Telegram e do redesenho de 23/09 ao corte de

## Diferença por origem

| Instalação atual | O que recebe |
|---|---|
| 1.34.2 oficial | Central, Cockpit, jornada de trabalho, Hermes/Telegram e atualização com prévia. |
| 1.36.1 do fork | Hermes/Telegram, redesenho de 23/09 e instalador/migrador por tag. |
| 1.37.x | Uma linha com as duas garantias de atualização, sem depender do updater antigo. |

O updater novo expande o manifesto em arquivos concretos. Ele preserva arquivos extras e
skills próprias, conteúdo privado, seeds existentes e bytes fora do bloco gerenciado do
`CLAUDE.md`. Na primeira atualização, `--baseline-dir` aponta a cópia íntegra da versão
instalada; arquivo diferente desse baseline é conflito. Um conflito cancela antes da primeira
escrita, mesmo com `--approve-plan`. Prévia, hash, lock, backup privado e rollback cobrem a
aplicação. Não há remoção automática de arquivos obsoletos. Queda abrupta de energia exige
inspeção do backup antes de retomar. Pós-update e telemetria não são executados.

## Piloto offline, sem publicar

Copie a pasta candidata ou o bundle para a máquina de teste. Para o bundle:

```bash
git clone -b codex/pacote-1380-20260927 /caminho/P-pacote-1380.bundle pacote-1380
```

Execute a partir de `pacote-1380`. Os comandos usam exclusivamente o pacote local:

```bash
CEREBRO_INSTALL_SOURCE_DIR="$PWD" node scripts/install.mjs --tag v1.38.0 --destination /caminho/cerebro-novo
CEREBRO_INSTALL_SOURCE_DIR="$PWD" node scripts/install.mjs --tag v1.38.0 --destination /caminho/cerebro-novo --apply
```

Para atualizar uma **cópia** de 1.36.1, extraia do bundle o baseline exato do fork. Guarde
skill e `CLAUDE.md` próprios na cópia para conferir preservação. Não execute o updater 1.36.1:

```bash
mkdir /caminho/baseline-1361
git archive 12a3395917b72f8ca88b65c2fc14e8156288d252 | tar -x -C /caminho/baseline-1361
CEREBRO_UPDATE_SOURCE_DIR="$PWD" node scripts/update.mjs --tag v1.38.0 --root /caminho/copia-1361 --baseline-dir /caminho/baseline-1361
```

A última linha mostra `plan_hash` e `conflicts`. Com `conflicts: []`, revise a lista e aplique
com o mesmo pacote e baseline:

```bash
CEREBRO_UPDATE_SOURCE_DIR="$PWD" node scripts/update.mjs --tag v1.38.0 --root /caminho/copia-1361 --baseline-dir /caminho/baseline-1361 --apply --approve-plan HASH_DA_PREVIA
node /caminho/copia-1361/scripts/cockpit.mjs --root /caminho/copia-1361
```

Se houver conflito, resolva-o na cópia e gere outra prévia. O hash anterior deixa de valer.
Para instalação 1.34.2, forneça como baseline a cópia íntegra da **mesma** 1.34.2; o
baseline 1.36.1 não serve. A operação pode ser repetida; a segunda prévia deve mostrar
arquivos inalterados. Bundle e pasta local são alternativas de transporte do mesmo commit.

## Telegram no piloto

No Cockpit local, abra **Conversar pelo Telegram**. Prepare o Hermes e autorize o Codex;
crie um bot no BotFather, cole o token no formulário local, envie `/start` na conversa
privada e confirme **Sou eu**. O Cockpit restringe a allowlist antes de ligar o serviço
e executar o diagnóstico. Faça isso só na máquina de piloto e após OK do Gabriel.
Critério pendente: observar no teste real autorização, identificação, acesso restrito,
diagnóstico e resposta com fonte; nenhuma mensagem foi enviada nesta preparação.
