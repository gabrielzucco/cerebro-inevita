# Pipeline — Briefing Comercial Inteligente

| Estado | Entrada | Saída | Gate |
|---|---|---|---|
| reunião identificada | calendário ou descrição | conta e objetivo | reunião inequívoca |
| contexto reunido | fontes autorizadas | fatos citáveis e lacunas | cada fato aponta para fonte |
| briefing revisado | contexto | briefing pré-call | pessoa confirma que usaria |
| call capturada | transcrição ou notas | fonte preservada | fala não é inventada |
| mudança extraída | antes + call | objeções, riscos e compromissos | evidência sustenta a mudança |
| diff aprovado | estado anterior + mudança | atualização proposta | nenhum write externo sem ok |
| encerrada | outputs | recibo + feedback | próximo passo tem dono e data |

Importação manual é um caminho de primeira classe. Conector reduz trabalho depois que o pipeline já
provou valor; não é pré-requisito para a primeira execução.
