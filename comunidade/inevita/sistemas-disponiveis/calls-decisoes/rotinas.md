# Rotinas — Calls em Decisões

## Por evento

- Quando uma transcrição real fica legível, abrir um run manual.
- Enquanto o julgamento estiver quente, revisar decisões, donos e pendências.

## Por execução

1. Identificar a call e a fonte autorizada.
2. Extrair derivados com proveniência.
3. Aplicar os evals.
4. Mostrar o artefato ao dono.
5. Salvar somente o que for aprovado.
6. Registrar recibo e feedback.
